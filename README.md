## Getting Started

### Prerequisites

Install a Java Development Kit (JDK).

Verify your installation:

```bash
java -version
javac -version
```

### Clone the repository

```bash
git clone https://github.com/pratikgodase07/PMIS-Java-Basics.git
cd PMIS-Java-Basics
```

### Compile and run a program

Navigate to the directory containing the Java file, then run:

```bash
javac Example.java
java Example
```

Replace `Example` with the actual filename and class name. These commands apply to simple programs without package declarations or additional dependencies.
